## Using the reports

Use the local reports to retrieve business descriptions, product information, risk disclosures, financial tables, and notes. Select the company and reporting period before retrieving relevant sections. Read only the evidence needed for the current question; loading every report into one model context is unnecessary.

Students choose how to clean, split, index, and retrieve the documents. Preserve headings, table relationships, report identity, and source locations. Store derived artifacts separately and keep the supplied files unchanged.

These are browser-saved HTML content snapshots of the public SEC primary documents. Separate exhibits and external images are not bundled. A reference to another file does not establish that the file is locally available. The database's filings table also contains metadata for other filings that have no local report copy.

Use the provided local database and reports for the main experiment. Distinguish actual results from risks, hypothetical scenarios, plans, and forecasts. Company report content retains its original attribution and rights.
